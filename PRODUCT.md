## Platform

web

## Purpose

Website for Bao Tang Van Hoc Viet Nam. Home navigation connects to works,
exhibitions, news, visiting, events, authors, and tickets. The current task is
to reproduce the supplied homepage PSD, not to redesign its visual identity.

## Stack

User-selected plain HTML, CSS, and JavaScript ES modules. Existing native
Custom Element shares the header across pages. No CSS or JS framework.

## Confirmed Assets and Constraints

- Authoritative design: PSD TRANG CHU.psd, 5333 by 19851 pixels.
- User-provided Drive folder contains a one-page PDF overview, section PNGs,
  eight fonts, PSD, and GLB models.
- The PSD takes precedence when a Drive PNG differs from it.
- Keep original models and design files intact; preserve existing page shells.
- Homepage imagery and fonts are served locally.
- The remaining page workflows are not specified and are still page shells.

## Open Decisions

Primary audience details, backend, ticket/payment workflows, official social
URLs, and hosting are not confirmed. Do not invent them.
