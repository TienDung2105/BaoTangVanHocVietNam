# Homepage Design Authority

Source: user-supplied PSD TRANG CHU.psd and accompanying Drive assets.
Canvas: 5333 x 19851. Reference display width: 1920.

The page reproduces the supplied dark historical hero, cream content field,
red section labels, layered editorial compositions, and footer. These explicit
reference choices override general aesthetic preferences from design skills.

Text is semantic HTML, not a flattened screenshot of the page. Native font
faces are local: Brother 1816, Uber Move Bold, Nexa, Proxima Nova, Qalogre,
and Vellago. PSD footer text uses Myriad Pro, which is not included in the
eight supplied fonts. Its original supplied text images preserve the desktop
lettering, with semantic text equivalents; mobile renders native Proxima Nova.

Desktop regions are measured from PSD layer bounds. Mobile switches to readable
flow/grid layouts because the source contains no separate mobile composition.
Do not claim pixel identity at arbitrary mobile widths.

Source priority: PSD > PDF overview > separately exported PNGs. The artifact
panel therefore uses the lute from the PSD, not the conflicting typewriter PNG.
The first historical hero uses its original photo and Multiply gold layer.

Reproduction scope: homepage. Existing menu destinations remain page shells;
no invented backend, biographies, payments, or social URLs.
